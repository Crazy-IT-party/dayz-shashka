Мод для DayZ: кавказская шашка (серебряный прибор с чернью, три дола), которая убивает любого с одного удара, тупится
от убийств и затачивается обратно на оселке, и её кожаные ножны, которые носят на поясе слева. Ножны с шашкой внутри
стоят под картиной с атакующими солдатами в деревенских домах.

Клиент-серверный мод `@Shashka`. Свои модели, текстуры и материалы повреждений; анимации и хват — от мачете.

## Что делает

- **Удар:** лёгкий или тяжёлый удар убивает игроков, заражённых и животных (число ударов настраивается: каждый
  снимает 1/N полного здоровья цели сверх урона самого клинка). Убийство засчитывается атакующему.
- **Дистанция:** больше, чем у мачете; сервер отправляет свои значения каждому клиенту при подключении.
- **Износ от убийств:** взмахи клинок не тупят, убийства тупят — повреждён после N убийств, сильно повреждён после
  N × 1,7, испорчен после N × 3 (счётчик сохраняется в предмете). Сила удара в каждом состоянии настраивается; по умолчанию испорченный клинок наносит только урон мачете.
- **Оселок:** стандартный рецепт «Заточить» поднимает состояние на один уровень (сильно повреждён → повреждён →
  отличное) и расходует заданную долю камня. Испорченный клинок заточить нельзя.
- **Ножны:** `SK_Sheath` вешаются на пояс слева (`Belt_Left`), на спину (слот на плечо) или на ремень рюкзака (не холщовой, курьерской или слинг-сумки) и держат клинок, рукоять видна. Из стандартных ремней
  их показывает военный ремень; кожаный ремень этот слот не отображает вовсе.
- **Другие слоты:** клинок без ножен на спине (слоты для оружия ближнего боя / на плечо) или на ремне рюкзака,
  рукоятью вверх — каждый по умолчанию выключен.
- **Появление в мире:** ножны с шашкой внутри стоят под картиной с атакующими солдатами в деревенских домах;
  мод сам их расставляет и пополняет.
- **Переводы:** все тринадцать языков DayZ.

## Состав

- `mod/Shashka` — аддон: конфиг, скрипты, модели (MLOD `.p3d`), текстуры (`.paa`), материалы (`.rvmat`) и
  stringtable. Упакуйте его в pbo с префиксом `Shashka` удобным вам инструментом и подпишите своим ключом.
- `mod/mod.cpp` — название и автор мода, для папки `@Shashka`.
- `mod/shashka.json` — настройки сервера со значениями по умолчанию.
- `missions/<карта>/shashka` — точки появления для стандартных карт: Чернарусь (358 точек), Ливония (190),
  Сахал (99).

## Сервер

1. Соберите папку `@Shashka` — `addons/shashka.pbo` (и его `.bisign`), `mod.cpp`, `keys/` с вашим `.bikey` —
   положите её в папку сервера и подключите на сервере и клиентах (`-mod=...;@Shashka`).
2. Настройки: скопируйте `mod/shashka.json` в `@Shashka/shashka.json` в папке сервера (он читается как
   `$CurrentDir:@Shashka/shashka.json`, поэтому папка там должна называться именно так). Без него сервер читает
   `$profile:Shashka/shashka.json` и при первом запуске записывает туда значения по умолчанию. Изменения
   применяются после перезапуска.

| ключ | по умолчанию | |
|---|---|---|
| `KillsToDamaged` | 10 | N: убийств до состояния «повреждён» |
| `BadlyDamagedFactor` | 1.7 | «сильно повреждён» после N × это убийств |
| `RuinedFactor` | 3.0 | «испорчен» после N × это убийств |
| `WhetstoneCostPercent` | 25 | доля оселка на одну заточку |
| `LightHitsToKill` / `HeavyHitsToKill` | 1 / 1 | ударов, чтобы убить кого угодно (тяжёлый включает удар на бегу) |
| `RangeLight` / `RangeHeavy` / `RangeSprint` | 1.9 / 1.9 / 3.8 | дистанция в метрах (мачете: 1,4 / 1,4 / 3,3) |
| `DamagePristine` / `DamageWorn` / `DamageDamaged` / `DamageBadlyDamaged` / `DamageRuined` | 1 / 1 / 1 / 1 / 0 | доля полного здоровья цели за один удар в этом состоянии клинка (делится на число ударов); 1 — убивает с одного удара, 0 — только урон мачете |
| `AllowBelt` | 1 | ножны на поясе |
| `AllowMeleeSlot` / `AllowShoulderSlot` | 0 / 0 | клинок без ножен на спине |
| `AllowBackpackSlot` | 0 | клинок без ножен на ремне рюкзака |
| `AllowSheathShoulder` / `AllowSheathBackpack` | 1 / 1 | ножны с клинком на спине (слот на плечо) / на ремне рюкзака |
| `SpawnUnderPaintings` | 1 | ножны под картиной с солдатами |
| `SpawnCount` | 4 | сколько таких точек одновременно заняты ножнами |
| `SpawnCheckMinutes` | 30 | как часто сервер их пополняет |

3. Появление в мире: скопируйте `missions/<карта>/shashka` в папку миссии (рядом с `init.c`) и добавьте её в
   `cfgeconomycore.xml` миссии, внутри `<economycore>`:

   ```xml
   <ce folder="shashka">
       <file name="types.xml" type="types" />
   </ce>
   ```

   `spots.json` содержит мировые координаты под каждой такой картиной на этой карте; `types.xml` задаёт предметам
   время жизни (nominal 0 — экономика их не создаёт, это делает мод). Без `spots.json` шашки просто не появляются.
